# Rank Hooper — Site (landing / legenda)

Página **separada** do aplicativo. Explica como o Rank Hooper funciona e leva o usuário para o app.

| Projeto | URL / repo |
|---------|------------|
| **Este site** | repositório `rank-hooper-site` |
| **Aplicativo** | https://bask-rank-hooper.vercel.app · repo `bask-rank-hooper` |

## Deploy na Vercel

1. Importe este repositório na Vercel (Framework: Other / static).
2. Deploy. Não precisa de variáveis de ambiente.
3. Opcional: domínio tipo `rankhooper.com` ou `site.rankhooper.app`.

## Local

Abra `index.html` no navegador ou:

```bash
npx serve .
```
